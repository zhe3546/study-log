## 1. 二分查找:你已经会它的思想了

**问题**:在一个**有序**数组里,查找某个数存不存在,存在就告诉下标。

比如在 `{1, 5, 9, 13, 22, 37, 45, 60, 81, 97}` 里找 45。

**笨办法(线性查找)**:从 a[0] 开始一个一个看,最多看 10 次。数组有 100 万个数就要看 100 万次——太慢。

**聪明办法**:想想你的猜数字游戏——1~100 怎么猜最快?**每次猜中间**,根据"大了/小了"砍掉一半。10 个数,一次砍一半:10 → 5 → 3 → 1,最多 4 次必找到。100 万个数呢?最多 20 次。**这就是二分查找,前提只有一个:数组必须有序**(所以昨天先学了排序——排序最大的用途之一就是给查找铺路)。

## 2. 二分的三个变量和一轮的流程

需要三个下标变量盯住"还没排除的范围":

```c
int low = 0;            // 范围的左边界(还没排除的最左)
int high = n - 1;       // 范围的右边界
```

每一轮做四件事:

1. 取中间:`int mid = (low + high) / 2;`(整数除法自动向下取整,正好用上)
2. 拿 `a[mid]` 和目标比,三种情况:
   - `a[mid] == key` → 找到了!返回 mid;
   - `a[mid] < key` → 中间这个太小,目标在**右半边**,丢掉左半:`low = mid + 1;`
   - `a[mid] > key` → 目标在**左半边**,丢掉右半:`high = mid - 1;`
3. 范围不断缩小,直到 `low > high`(范围被挤没了)——说明不存在,返回 -1。

用 `{1, 5, 9, 13, 22, 37, 45, 60, 81, 97}` 找 45,纸上走一遍:

```
low=0 high=9 → mid=4, a[4]=22 < 45 → 目标在右半,low=5
low=5 high=9 → mid=7, a[7]=60 > 45 → 目标在左半,high=6
low=5 high=6 → mid=5, a[5]=37 < 45 → low=6
low=6 high=6 → mid=6, a[6]=45 == 45 → 找到,下标 6!
```

4 轮解决。**建议你先照这个格式,自己纸上推一遍找 81 的过程,再写代码。**

## 3. 完整代码(先自己写,卡 20 分钟再看)

```c
int low = 0, high = n - 1;
int pos = -1;                       // 先假设找不到
while (low <= high) {               // 注意是 <= :low==high 时范围还剩 1 个数,仍要查
    int mid = (low + high) / 2;
    if (a[mid] == key) {
        pos = mid;                  // 记录答案
        break;                      // 找到了,没必要再找
    } else if (a[mid] < key) {
        low = mid + 1;
    } else {
        high = mid - 1;
    }
}
// pos == -1 表示不存在;否则 pos 是下标
```

**两个边界,考试和面试最爱挖**:
1. 循环条件是 `low <= high` 不是 `<`——写成 `<` 会漏判"范围只剩一个数"的情况;
2. 缩范围必须 `mid + 1` / `mid - 1`,不能写 `low = mid`——否则范围可能永远缩不小,死循环。

## 4. 函数:把代码变成积木

**为什么需要函数**:你的 maopao.c 现在 39 行全挤在 main 里。如果下个程序也要排序,难道复制粘贴一遍?改 bug 还要改两处?**函数 = 把一段代码打包、起名、随取随用**——像数学里 f(x) 一样,给个输入,还个输出。

**语法三件套**:

```c
返回类型 函数名(参数列表)     // ← 函数头:说明书
{
    函数体;                    // ← 干活的地方
    return 结果;               // ← 交货(返回类型是 void 就不用 return 值)
}
```

**例子:判断素数的函数**。素数 = 大于 1 且只能被 1 和自己整除的数(2, 3, 5, 7, 11...)。

```c
int isPrime(int n)              // 输入一个 int,返回一个 int(1=是素数, 0=不是)
{
    if (n < 2) {
        return 0;               // 0、1、负数都不是素数,直接交货
    }
    for (int i = 2; i * i <= n; i++) {   // 试除:只需要试到根号 n
        if (n % i == 0) {
            return 0;           // 找到别的因数 → 不是素数
        }
    }
    return 1;                   // 全试完了都除不尽 → 是素数
}
```

**在 main 里调用**(函数定义写在 main 上面,C 编译器从上往下读,先认识才能用):

```c
if (isPrime(x) == 1) {
    printf("%d 是素数\n", x);
}
```

**两个新知识展开讲**:
- `return` = 立刻交货并离开这个函数,**后面的代码不再执行**——所以 isPrime 里找到因数直接 return 0,不用 flag 变量绕弯;
- 试除到 `i * i <= n` 就够:如果 n 有个大于 √n 的因数,必有个对应的小于 √n 的因数早就被试到了。这不是玄学,是效率意识——二分、试除优化,都是"少干活"的智慧。
