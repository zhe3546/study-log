## 1. 什么是排序,为什么从冒泡学起

排序 = 把一堆乱序的数按从小到大(或从大到小)排好:`5 2 8 1 9` → `1 2 5 8 9`。

排序算法有十几种,冒泡是**最简单、最直观**的一种——它不快,但思想纯净,是理解其他排序的入口。就像学武功先学站桩:不指望它打天下,但没有它后面全站不稳。

## 2. 核心思想:相邻比较,大的往后"冒"

想象一排水杯,里面水位高低不一。规则只有一条:**从左到右,相邻两个比较,如果左边比右边高,就交换它们**。

用 `[5, 2, 8, 1, 9]` 走一遍**第一轮**(建议拿纸笔跟着画):

```
初始:  5  2  8  1  9
比 5,2: 5>2 交换 →  2  5  8  1  9
比 5,8: 5<8 不换 →  2  5  8  1  9
比 8,1: 8>1 交换 →  2  5  1  8  9
比 8,9: 8<9 不换 →  2  5  1  8  9
```

**第一轮结束,观察到了什么?** 最大的 9 已经被"顶"到了最右边——像水底的气泡一路冒到水面,这就是"冒泡"名字的由来。

那么第二轮就不用管最后那个 9 了,只对前面 4 个重复同样的过程,把第二大的顶到倒数第二位……**每进行一轮,就确定一个"最大值"的最终位置,需要管的数少一个。**

5 个数需要几轮?**4 轮**(n 个数需要 n-1 轮:当 n-1 个都归位了,最后一个不用排)。

## 3. 翻译成代码:双层循环

先把"交换两个变量"这个零件做出来(本周五指针课会讲透它背后的原理):

```c
int t = a[j];       // 先把左边的值倒进临时杯子 t
a[j] = a[j+1];      // 右边的值倒进左边
a[j+1] = t;         // t 里存的旧值倒进右边
```

⚠️ 交换**必须用第三个临时变量**,直接 `a[j]=a[j+1]; a[j+1]=a[j];` 会把左边的值弄丢——这是经典错误,以后面试都可能被问。

然后是整体结构,**两个循环各管一件事**:

```c
for (int i = 0; i < n - 1; i++) {            // 外层:管"第几轮",n 个数要 n-1 轮
    for (int j = 0; j < n - 1 - i; j++) {    // 内层:管"这一轮里相邻比较"
        if (a[j] > a[j+1]) {                 // 左边比右边大 → 交换
            int t = a[j];
            a[j] = a[j+1];
            a[j+1] = t;
        }
    }
}
```

**三个关键点,逐一讲透**:

1. **外层 `i < n - 1`**:10 个数排 9 轮。对应上面"每轮归位一个"的分析;
2. **内层 `j < n - 1 - i`**:两个原因。① 每轮结束,末尾已有 i 个数归位,不用再比,所以比较范围一轮比一轮短;② j 最大只能到"要比较的最后一个位置的前一格",因为访问的是 `a[j]` 和 `a[j+1]`——j 再多走一步,`a[j+1]` 就越界了;
3. **比较的是 `a[j] > a[j+1]`**:从小到大排。想从大到小?把 `>` 改成 `<` 就行。
