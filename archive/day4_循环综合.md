## 1. 嵌套循环:循环里再套循环

```c
for (int i = 1; i <= 3; i++) {          // 外层:走 3 轮
    for (int j = 1; j <= 2; j++) {      // 内层:每轮走 2 遍
        printf("i=%d j=%d\n", i, j);
    }
}
```

输出:
```
i=1 j=1
i=1 j=2
i=2 j=1
i=2 j=2
i=3 j=1
i=3 j=2
```

**执行模型(重要,脑子里要有这个画面)**:外层每走 1 步,内层就要**完整跑完一圈**。总执行次数 = 外层次数 × 内层次数,上面是 3 × 2 = 6 次。

⚠️ 两个 i、j 是**不同的变量**,名字一定不能重复;习惯上外层 i、内层 j。

## 2. 练习一:九九乘法表(嵌套循环的经典)

目标输出(下三角形式):

```
1*1=1
1*2=2 2*2=4
1*3=3 2*3=6 3*3=9
...中间略...
1*9=9 2*9=18 3*9=27 ... 9*9=81
```

**分析(先想清楚再动手)**:
- 一行里有好几个算式 → 需要**内层循环**负责一行;
- 一共 9 行 → **外层循环**控制行;
- 关键细节:第 i 行只打印到 `i*i` 为止,所以内层 j 的范围是 `1 到 i`,不是 `1 到 9`;
- 同一行内不换行,打完一行再换行——用 printf 的两个新朋友:
  - `\t` 制表符,相当于按一次 Tab 键,让列对齐;
  - `\n` 换行,你已经认识。

**骨架(自己先别看)**:

```
for (i = 1 到 9) {
    for (j = 1 到 i) {
        打印 j*i=j*i 的值,后面跟 \t
    }
    打印 \n 换行
}
```

写出来后和上面的目标输出逐行对比。

## 3. 练习二:水仙花数(拆数字)

**水仙花数**:一个三位数,它的每个数字的立方和等于它自己。例如 `153 = 1³ + 5³ + 3³ = 1 + 125 + 27`。

目标:打印 100~999 之间**所有**水仙花数(一共 4 个,做对了就知道是哪 4 个)。

**这题真正要学的是"拆数字"——从 153 里拆出 1、5、3**:

```c
int n = 153;
int ge  = n % 10;        // 个位:153 除以 10 余 3
int shi = n / 10 % 10;   // 十位:153/10=15,15%10=5
int bai = n / 100;       // 百位:153/100=1
```

`/` 和 `%` 一上一下配合,是**整数拆解的标准工具**,以后做题(逆转数字、数位统计)全靠它。

**思路**:
```
for (n = 100 到 999) {
    拆出百十个位
    if (百³ + 十³ + 个³ == n) 打印 n
}
```

一个提醒:立方别用 `pow()`,那是浮点运算有精度坑,直接 `bai*bai*bai` 相乘,又快又准。
