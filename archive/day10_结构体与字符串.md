## 第 0 步 · 先还三笔 bug 债（20 分钟，别跳过）

我 review 了你这几天的代码，**指针部分学得很扎实**（`swap.c` 的地址传递、`bianli.c` 用 `for (int *p = a; p < a+10; p++)` 遍历数组、`guancha.c` 观察步长，全都一次写对，指针这关你过了）。但有三个 bug 要修：

### 债 1 · `qiuhe.c`：行求和时 `sum` 没清零（最严重）

```c
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 4; j++) {
        sum += a[i][j];      // sum 一直累加,从不归零
    }
    printf("%d", sum);
}
```

你打印出来的第 2 行其实是"前两行的总和"，第 3 行是"三行总和"。
**修法**：`sum` 必须在**每一行开始之前**清零：

```c
for (int i = 0; i < 3; i++) {
    sum = 0;                 // ← 加这一行,每行重新计数
    for (int j = 0; j < 4; j++) sum += a[i][j];
    printf("第%d行总分:%d\n", i + 1, sum);
}
```

列平均那个 `p` 是**同一个 bug**：`p = 0;` 要写在每列循环开头。

### 债 2 · `qiuhe.c`：擂主初值 `max = 0`（老熟人第三次出现）

如果全班成绩都是负数（或你这题输入的全是负数），`max` 永远不会被更新，最后打印的"最高分 0"是假的。
**修法**：擂主必须用数组里的真实元素加冕 —— `int max = a[0][0];`，输入完成后再赋值。（这条你在 `leitai.c` 里就踩过一次，今天是第三次，这次之后应该能形成条件反射了。）

`h` 和 `l` 同理，要跟着 `max` 一起初始化成 `0`。

### 债 3 · `100.c`：0 和 1 不是素数

```c
if (i <= 2) printf("%d ", i);    // i 从 0 开始,会把 0 和 1 也打印出来
```

数学规定：**小于 2 的数都不是素数**。你的 `100.c` 会多打印 `0` 和 `1` 两个数。
正确做法（顺便把循环改成调用你已经写好的 `isprime` 函数）：

```c
for (int i = 2; i <= 100; i++) {
    if (isprime(i)) printf("%d ", i);
}
```

正确答案：**100 以内共 25 个素数**（2 3 5 7 11 ... 97）。数一下你输出的是不是 25 个。

> 顺带说个观念：**`isprime` 你写一次，以后永远能用** —— 这就是函数的意义。这种"写一次、用一辈子"的工具函数，要养成单独存一个文件（比如 `isprime.c`）的习惯。

## 第一部分 · 字符串：C 语言里最别扭的东西

### 1. 从你已经会的出发

```c
char c = 'A';
```

**注意两个引号的区别**（新手第一天必混）：

| 写法 | 意思 | 类型 |
|---|---|---|
| `'A'` | 单个字符 A | char |
| `"A"` | 字符串（其实是两个字节：`A` + `\0`） | char 数组 |

### 2. 新知识①：C 语言**没有** string 类型

Java/Python/C++ 里都有 `String s = "hello";`，**C 没有**。C 的字符串只有一种形式：

> **字符数组 + 一个结束哨兵 `\0`**

```c
char name[20] = "张三";
```

内存里实际是这样（后面 16 个格子空着）：

```
[张][三][\0][ ][ ]...[ ]
```

### 3. 新知识②：`'\0'` 空字符——C 字符串的命门

C 语言不知道你的 char 数组里"哪几个格子是有内容的"。它的规矩极其朴素：

> **从第一个字符开始读，一直读到 `'\0'` 就认为字符串结束了。**

`'\0'` 是 ASCII 码为 0 的那个字符 —— 它不是字母 0，不是空格，是一个"看不见的哨兵"。

**由此推出一条铁律**：

> `char name[20]` 最多只能装 **19 个**字符，第 20 个位置必须留给 `\0`。
> 一旦 `\0` 丢了（比如刚好装满 20 个字符），printf 会一直往下读到内存里的垃圾，直到碰巧遇到一个 0 才停 —— 这就是**乱码/烫烫烫**的来源。

**新知识③：字符串字面量自带 `\0`**
`"hello"` 看起来 5 个字母，实际占 **6 个字节**（h e l l o \0）。所以 `strlen("hello")` 是 5，`sizeof("hello")` 是 6。

### 4. 输入和输出字符串

```c
char name[20];
scanf("%s", name);        // ← 注意:name 前面【没有 &】
printf("%s\n", name);
```

**新知识④：为什么字符串 scanf 不用加 `&`？**（这是你这两周学的知识第一次串起来）

回想 Day 9 的指针：**数组名 `name` 本身就是首元素的地址**。而 scanf 要的恰恰就是"往哪儿写"的地址。

- `scanf("%d", &a)` —— a 是普通变量，要 `&` 取地址；
- `scanf("%s", name)` —— name 已经是地址了，再加 `&` 反而类型错误。

**新知识⑤：`%s` 遇到空格就停**
输入 `Zhang San`，`name` 里只会装进 `Zhang`。要读一整行（含空格）用：

```c
fgets(name, 20, stdin);   // 读入一整行,最多 20 个字符,包含空格
```

（fgets 会把回车也读进去，今天先知道有这么回事，项目里用到我再细讲。）

### 5. 新知识⑥：三个必会的字符串函数（要加 `#include <string.h>`）

| 函数 | 作用 | 例子 |
|---|---|---|
| `strlen(s)` | 求长度（**不含 `\0`**） | `strlen("hello")` → 5 |
| `strcmp(a, b)` | 比较大小 | **相等返回 0**（不是 1！） |
| `strcpy(dst, src)` | 把 src 复制给 dst | `strcpy(name, "张三")` |

**新知识⑦（今天最经典的坑）：为什么字符串不能用 `==` 比较？**

```c
if (name == "张三")    // ❌ 永远不成立
```

因为 `name` 是**地址**，`"张三"` 也是**地址**（字符串字面量在内存里的存放位置）——两个地址永远不可能相等，这个 if 一辈子进不去。

正确写法：

```c
if (strcmp(name, "张三") == 0)   // ✅ 相等时 strcmp 返回 0
```

记住这个反直觉的地方：**strcmp 返回 0 表示相等**（返回负数表示 a 小、正数表示 a 大）。

**新知识⑧：字符数组不能用 `=` 赋值**

```c
char name[20];
name = "张三";              // ❌ 编译报错
strcpy(name, "张三");        // ✅ 正确
```

原因还是那个：数组名是**常量地址**，不能被赋新值。只能把内容"搬"进去。
> 预告：这个反人类的设计，等你 10.25 学 C++ 的 `string` 类就彻底解脱了 —— `string name = "张三";` 一句话搞定。你现在受的这份罪，将来会变成"原来 C++ 帮我们藏了这么多事"的通透感。

### 6. 练习一：自己实现 strlen（不许用库函数）★必做

```c
int myLen(char s[])
{
    int i = 0;
    while (s[i] != '\0') {    // 一直走到哨兵为止
        i++;
    }
    return i;
}
```

**讲透这个套路**：这是**遍历字符串的标准写法** —— `while (s[i] != '\0')`。以后凡是处理字符串（统计、查找、替换、反转），外层都是这个循环。它和你遍历数组用的 `for (i = 0; i < n; i++)` 是两种模式：数组用**长度**控制，字符串用**哨兵**控制。

写完测：`myLen("hello")` → 5，`myLen("")` → 0。

## 第二部分 · 结构体：把一堆相关的数据打包

### 1. 先看痛点：为什么非要有结构体

现在要存 3 个学生，每人有**学号、姓名、3 门成绩**。用你现在会的知识只能这样：

```c
int   id[3];
char  name[3][20];
int   score[3][3];
```

三个**平行数组**，靠下标"对齐"——第 2 个学生的信息散落在 `id[1]`、`name[1]`、`score[1]` 三处。

致命问题来了：**按成绩排序时，你得同时交换三个数组里对应位置的元素**，漏一个就全乱套。这正是 Array 的软肋：它只能装"同类型的一排"，装不了"一个事物的多个属性"。

**结构体就是来解决这个的**：把一个学生相关的所有数据打包成一个整体，排序时**整体交换**，绝不会错位。

### 2. 新知识⑨：定义结构体 = 造一个新的"数据类型"

```c
struct Student {
    int    id;
    char   name[20];
    int    score[3];
    double avg;
};                    // ← 这个分号【千万不能漏】
```

理解这一段的三个要点：

1. **这里定义的是"模板"（类型），不是变量** —— 相当于你设计了一张表格的表头，还没有填数据。类比：`int` 是类型，`int a;` 才是变量。
2. 里面可以装**任意类型**的成员，包括数组、字符串、甚至别的结构体。
3. **末尾的分号是新手第一大编译错误来源** —— 因为 `}` 后面跟着 `;` 看起来很怪，但必须有。

### 3. 造出实体并赋值

```c
struct Student s1;              // 造出一个学生实体

s1.id = 1001;                   // 普通成员:直接赋值
strcpy(s1.name, "张三");         // 字符串成员:必须用 strcpy(新知识⑧)
s1.score[0] = 90;
s1.avg = 88.5;
```

**新知识⑩：`.` 点号运算符** —— "的"的意思。`s1.id` 读作"s1 的 id"。

### 4. 结构体数组（明天项目的核心数据结构）

```c
struct Student stu[3];          // 3 个学生

for (int i = 0; i < 3; i++) {
    printf("请输入第%d个学生的学号和姓名:", i + 1);
    scanf("%d %s", &stu[i].id, stu[i].name);   // id 要 &,name 不要 &
}
```

注意这一行里 `&stu[i].id` 和 `stu[i].name` 的差别——**正好把新知识④复习了一遍**。

### 5. 新知识⑪：`->` 箭头运算符

如果你拿到的是**指向结构体的指针**：

```c
struct Student *p = &stu[0];

(*p).id = 1002;     // 这样写对,但太啰嗦(括号不能少,因为 . 的优先级比 * 高)
p->id = 1002;       // ✅ 简写,完全等价 —— 读作"p 指向的那个的 id"
```

今天用得少（数组形式用 `.` 就够了），但你会在别人的代码里天天见到它，先认得。

### 6. 练习四：结构体数组排序 ★今天的重头戏

**题目**：输入 3 个学生的学号、姓名、成绩，按成绩**从高到低**排序后输出。

**思路**：把你 Day 5 写的冒泡排序拿来，只改一个地方 ——

```c
// 原来交换两个 int:
int t = a[j];
a[j] = a[j+1];
a[j+1] = t;

// 现在交换两个【结构体】:
struct Student t = stu[j];
stu[j] = stu[j+1];
stu[j+1] = t;
```

**新知识⑫（这是结构体最大的好处）：结构体支持整体赋值**
`t = stu[j]` 会把这个学生**所有成员一次性复制过去** —— 学号、姓名、三科成绩全跟着走，绝不会出现"成绩换了但名字没换"的错位。

这就是结构体的价值：**把"一堆要一起动的数据"绑成一个整体，动就一起动。**
