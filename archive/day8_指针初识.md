## 1. 内存:一条街,无数个带门牌号的房间

你的电脑内存可以理解为一条超长的街,街上密密麻麻是**字节房间**,每个房间有唯一编号——这个编号就叫**地址**。

程序运行时做的每一件事,本质上都是"在第 XXXX 号房间里存/取东西"。

```c
int a = 10;
```

这句话的实际含义是:向系统申请 4 个连续房间(因为 int 占 4 字节),把 10 放进去,并把这个地址组的起点起个小名叫 `a`。

你可以亲眼看到它的门牌号:

```c
printf("%d\n", a);    // 10        → 房间里的东西
printf("%p\n", &a);   // 0000001A3B4FFA2C → 房间的门牌号(每次运行可能不同)
```

**新知识:`&` 是取地址运算符**,`&a` 读作"a 的地址"。

**新知识:`%p` 是地址的专用占位符**(p = pointer),打印出来的是十六进制,像 `0x1a3b4ff` 这样。⚠️ printf 里地址必须用 `%p`,用 `%d` 是错的。

**试一试**:多运行两次你的程序,你会发现地址**每次都不一样**——这是操作系统的保护机制(ASLR),防止坏人算出你的内存布局。地址会变,但地址这个概念不虚。

## 2. 指针变量:专门存门牌号的变量

普通变量存**数据**(10、3.14、'A');**指针变量存的是另一个变量的地址**。

```c
int a = 10;        // 普通变量,存 10
int *p = &a;       // 指针变量 p,存的是 a 的地址(门牌号)
```

读法:`int *p` 声明一个"指向 int 的指针"。这个 `*` 在这里**不是乘法**,是类型标记,意思是"p 是地址型变量,它指向的那块地方里装的是个 int"。

现在有三种写法,含义完全不同,这是指针的第一道关:

| 写法 | 含义 | 类比 |
|---|---|---|
| `p` | 指针变量本身的值 = a 的地址 | 记着门牌号的**纸条** |
| `*p` | 到 p 记的那个地址去,取出里面的值 = 10 | **按门牌号找过去**,进屋拿东西 |
| `&a` | a 的地址 | a 家的门牌号 |

所以 `*p` 和 `a` 完全等价——它们是同一个房间的两种说法:

```c
printf("%d\n", *p);    // 10
*p = 20;               // 通过地址,把房间里的内容改成 20
printf("%d\n", a);     // 20 ← a 被改了!没碰 a,却改了 a
```

**这是指针的第一个震撼**:你动的是 `*p`,变的却是 `a`——因为它们指向同一个房间。

## 3. 谜底揭晓:scanf 为什么必须加 &

Day 2 你就记住了"scanf 变量前必须加 &"，当时我说 10 月会揭晓,今天揭晓:

```c
scanf("%d", &a);
```

**scanf 的工作方式**:它要把你从键盘输入的数,**放到某个内存位置**。所以它需要的不是"值",而是"往哪儿放"——必须给它**地址**。

如果你写成 `scanf("%d", a)`,scanf 拿到的是 10(值),它就把 10 当作地址,往第 10 号房间写数据——那地方是系统的地盘,操作系统当场击毙你的程序。

**这就是你 Day 2 那次段错误(Segmentation fault)的真相**。当时我问你"a 前面少了 &",现在你知道了:不是规矩,是地址。

回去做个实验(必做):在程序里写 `scanf("%d", a);` 编译运行,看着它崩——从今天起,这种崩溃你不再是"不知道为什么",而是"我知道它往哪写了"。

## 4. 三种打印,把自己绕晕之前先理清

```c
int a = 10;
int *p = &a;
printf("a的值: %d\n", a);      // 10
printf("a的地址: %p\n", &a);   // 0x...A2C
printf("p里存的: %p\n", p);    // 0x...A2C  和 &a 一模一样
printf("p指向的值: %d\n", *p); // 10         和 a 一模一样
printf("p自己的地址: %p\n", &p); // 0x...B10 指针自己也有地址!
```

最后那行是个思维升级:**指针本身也是变量,也住在某个房间里,也有地址**。以后你会见到"指向指针的指针"(二级指针,存地址的地址),但现在不用管,你只要知道它存在。

## 5. 指针的两条铁律

**铁律一:类型必须匹配**
`int *p` 只能指向 int,`double *q` 只能指向 double。因为指针不只是地址,它还声明了"从这个地址开始,往后几个字节算一个数据"——int 4 字节,double 8 字节。类型不匹配,取出来的值就是错的。

**铁律二:指针必须先有指向,才能用 `*` 去取**

```c
int *p;        // 声明了,但没指向任何地方!p 里是垃圾地址
*p = 100;      // ❌ 往一个随机的房间写东西 → 段错误
```

未初始化的指针叫**野指针**,和你猜数字里"未初始化的 b"、擂台里"未初始化的 a[0]"是**同一个 bug 家族的第三次变身**:用了还没准备好的东西。

安全写法:声明时就指向,或者明确置空:

```c
int a = 10;
int *p = NULL;    // NULL = 空的,谁也不指(NULL 是大写,本质就是地址 0)
p = &a;           // 现在有指向了
```

**练习一:地址观察（15 分钟)**
定义 int、double、char 三个变量,把它们的**地址**都打出来,观察地址之间的差值(这就是不同类型占的字节数,等于 sizeof 的结果)。

**练习二:隔空改值（15 分钟)**
```c
int a = 5;

```
再加一句:用scanf 通过指针读入——`scanf("%d", p);`(注意:这里**没有 &**!因为 p 本身就是地址,想想为什么)。
