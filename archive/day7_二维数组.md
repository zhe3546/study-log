## 1. 从一维到二维:为什么需要"表格"

一维数组是一**排**格子,编号一个数就够:`a[3]`。

但有些数据天生是"表格"——比如 3 个学生 × 4 门课的成绩:

| | 语文 | 数学 | 英语 | 体育 |
|---|---|---|---|---|
| 张三 | 85 | 92 | 78 | 90 |
| 李四 | 76 | 88 | 95 | 84 |
| 王五 | 90 | 73 | 82 | 79 |

定位一个成绩需要**两个**数字:第几行、第几列。这就是二维数组:

```c
int score[3][4];     // 3 行 4 列,共 12 个 int 格子
```

理解方式:**二维数组 = 一维数组的每个格子又是一个一维数组**(3 个"行",每行 4 个格子)。这个视角下周讲指针时会升级,先记住字面用法。

## 2. 声明、初始化、访问

```c
int a[3][3] = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
```

- **行下标在前,列下标在后**:`a[1][2]` = 第 1 行第 2 列 = 6(都是从 0 数!);
- 越界规则同一维:`a[1][2]` 合法(3×3),`a[3][0]` 或 `a[2][3]` 越界,编译器不报错、运行出鬼;
- 习惯命名:外层循环 i 管行,内层 j 管列——**i 行 j 列,顺序别反**。

## 3. 遍历:嵌套循环正式回归

```c
for (int i = 0; i < 3; i++) {          // i:第几行
    for (int j = 0; j < 4; j++) {      // j:第几列
        printf("%d ", a[i][j]);
    }
    printf("\n");                       // 一行打完换行——乘法表的感觉回来了
}
```

执行模型和九九乘法表一模一样:**外层走 1 行,内层把这一行的 4 列走完**。

配 scanf 输入同理:

```c
for (int i = 0; i < 3; i++)
    for (int j = 0; j < 4; j++)
        scanf("%d", &a[i][j]);
```

## 4. 核心思维:固定一个下标,遍历另一个

这是二维数组题的万能钥匙,拿成绩表说:

- **第 i 行的所有成绩**(某学生的 4 门课):固定行,列动 → 遍历 `a[i][j]`,j 从 0 到 3;
- **第 j 列的所有成绩**(某门课的 3 个学生):固定列,行动 → 遍历 `a[i][j]`,i 从 0 到 2。

```c
// 第 1 个学生的总分
int sum = 0;
for (int j = 0; j < 4; j++)
    sum += a[0][j];

// 数学课(第 1 列)的全班平均分
int total = 0;
for (int i = 0; i < 3; i++)
    total += a[i][1];
```

**看懂这两段的区别,二维数组就懂了。**

## 5. 练习一:3×3 矩阵转置(今日主菜)

**转置** = 沿主对角线(左上到右下)翻折,行列互换:

```
1 2 3        1 4 7
4 5 6   →    2 5 8
7 8 9        3 6 9
```

规律:**原来的 a[i][j],转置后在 b[j][i]**。两种写法任选(建议都试):

**写法 A(新数组)**:
```c
int b[3][3];
for (int i = 0; i < 3; i++)
    for (int j = 0; j < 3; j++)
        b[j][i] = a[i][j];
```

**写法 B(原地交换,省内存)**:沿对角线,只交换"上三角和下三角"对应的两个格子:
```c
for (int i = 0; i < 3; i++)
    for (int j = i + 1; j < 3; j++) {     // j 从 i+1 开始:只走上三角,不碰对角线
        int t = a[i][j];
        a[i][j] = a[j][i];
        a[j][i] = t;                       // 又是三行交换,第几次见了?
    }
```

⚠️ 写法 B 里如果 j 从 0 开始,每对格子会**交换两次 = 换回去白干**——想想为什么。
